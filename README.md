# КР-08. Оптимальне розміщення датчиків як задача покриття множини: жадібний алгоритм проти LP-округлення

Репозиторій курсової роботи з дисципліни **«Алгоритми розв'язання задач у технічних науках»** (ДУ «Житомирська політехніка», спеціальність F3 «Комп'ютерні науки», 2026).

## Призначення
Дослідження та експериментальне порівняння двох принципово різних підходів до NP-важкої задачі зваженого покриття множини (Weighted Set Cover та $k$-Set Cover із резервуванням) для оптимального розміщення датчиків контролю метану/температури у промислових виробках:
1. **Підхід A (`src/method_a/GreedySolver.cs`)** — комбінаторний жадібний алгоритм із лінивою пріоритетною чергою (`PriorityQueue<int, double>`) за питомою вартістю $c_j / |	ilde{S}_j|$ та теоретичною гарантією $H(d) = \sum_{r=1}^d 1/r pprox \ln d + 1$.
2. **Підхід B (`src/method_b/`)** — релаксаційно-поліедральний підхід на основі неперервної LP-релаксації (`GLOP`):
   - **B1 (`LpThresholdRoundingSolver.cs`)**: детерміноване порогове округлення за порогом $1/(f-k+1)$ з гарантією $f$-апроксимації;
   - **B2 (`LpRandomizedRoundingSolver.cs`)**: рандомізоване округлення з імовірністю $p_j = \min(1, lpha x_j^*)$, жадібною добудовою та відсіканням надлишкових датчиків (`reverse-delete pruning`).
3. **Еталон коректності (`src/reference/ExactMilpSolver.cs`, `SolutionVerifier.cs`)** — точний розв'язувач ЦЛП (`CBC`/`SCIP`), нижня межа неперервної релаксації $	ext{LP}^*$ та незалежний верифікатор допустимості покриття.

## Апаратні та програмні вимоги
- **ОС:** Windows 10/11 (x64), Linux (x64) або macOS (x64/ARM64)
- **Середовище виконання:** .NET SDK 8.0+ (`dotnet --version`)
- **Оперативна пам'ять:** не менше 4 ГБ (пікове споживання під час прогону $n = 10^5$ становить до 250 МБ)

## Відтворення результатів однією командою

Укажіть свій порядковий номер у списку групи в параметрі `-StudentNumber` (за замовчуванням `1`, що відповідає `seed = 1000 * 1 + 8 = 1008`):

```powershell
# 1. Малий режим (до 1–2 хвилин: збірка, тести коректності, малий прогін, статистика й графіки — для демонстрації на захисті):
```
