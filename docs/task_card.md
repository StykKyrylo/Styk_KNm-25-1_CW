# Картка задачі курсової роботи (Додаток А)

| Поле | Значення |
|---|---|
| **Тема (шифр і назва)** | КР-08. Оптимальне розміщення датчиків як задача покриття множини: жадібний алгоритм проти LP-округлення |
| **Здобувач, група, seed** | [ПІБ], група [Група]; `seed = 1000 × (номер у списку) + 8` |
| **Предметний контекст** | Для контролю концентрації метану, температури або вібрації у гірничій виробці чи виробничому цеху датчики можна встановити у m кандидатних позиціях з різною вартістю монтажу й обслуговування. Кожна позиція покриває підмножину контрольних точок з урахуванням радіуса дії та непрозорих перешкод (ціликів/стін), і потрібно обрати набір позицій мінімальної сумарної вартості, що покриває кожну точку щонайменше k датчиками. |
| **Формальна постановка** | **Вхід:** множина контрольних точок $U$ ($|U|=n$), сімейство підмножин $S_1, \dots, S_m \subseteq U$, вартості $c_j > 0$, кратність резервування $k \in \{1, 2, 3\}$. **Вихід:** підмножина індексів $I \subseteq \{1,\dots,m\}$. **Критерій якості:** $\min \sum_{j \in I} c_j$. **Обмеження:** $\sum_{j \in I: i \in S_j} 1 \ge k \;\; orall i \in U$. **Очікувані розмірності:** $n \in [10^2; 10^5]$, $m \in [60; 4000]$. |
| **Підхід A** | **Жадібний алгоритм (Greedy Set Cover / Multi-cover)** із лінивою пріоритетною чергою за відношенням $c_j / |	ilde{S}_j|$. **Виграш:** майже лінійний час $O(\sum_j |S_j| \log m)$, мала пам'ять, масштабування до $n = 10^5$. **Слабкість:** вразливість до «поперечних» структур (адверсарні екземпляри дають похибку $\Omega(\ln n)$). |
| **Підхід B** | **LP-релаксація + округлення:** (B1) детерміноване порогове округлення за порогом $1/(f-k+1)$ та (B2) рандомізоване округлення з імовірністю $\min(1, lpha x_j^*)$, жадібною добудовою й reverse-delete очищенням. **Виграш:** враховує глобальну структуру перетинів, розв'язує адверсарні екземпляри Хватала точно і дає нижню межу $	ext{LP}^*$. **Слабкість:** висока вартість розв'язання LP на великих розмірностях. |
| **Чому принципово різні** | Підхід A — комбінаторний локально-жадібний метод із логарифмічною гарантією $H(d)$, тоді як підхід B — релаксаційно-поліедральний метод неперервної оптимізації з детермінованим/ймовірнісним округленням дробового вектора $x^*$. |
| **Еталон коректності** | (1) Незалежний верифікатор `SolutionVerifier` (перевірка $	ext{cov}(i) \ge k$ для всіх $i \in U$ та суми вартостей); (2) Точний розв'язувач MILP (Google OR-Tools CBC/SCIP) на $n \le 1000$; (3) Нижня межа неперервної релаксації $	ext{LP}^*$ (GLOP). |
| **Дані** | Генератор `InstanceGenerators.cs` з фіксованим зерном: (1) геометричні екземпляри на відкритій площині (`Plane`), (2) виробка з непрозорими перешкодами-стінами (`MineObstacles`), (3) адверсарні екземпляри Хватала–Джонсона (`Adversarial`), (4) анонімізована схема вентиляційного горизонту шахти (`data/mine_horizon_plan.json`, CC-BY-4.0). |
| **Метрики** | Емпіричне відношення $	ext{Cost}/	ext{LP}^*$ та $	ext{Cost}/	ext{OPT}$ (безрозм.), час підготовки й час розв'язання (мс), пікова пам'ять (МБ); агрегація за екземпляром (медіана, IQR, 95% ДІ бутстрепом). |
| **Попередні гіпотези** | **H1:** На геометричних екземплярах (`Plane`, `MineObstacles`) медіанне відношення $	ext{Cost}/	ext{LP}^*$ для жадібного методу та LP-рандомізованого округлення не перевищує $1.15$, що значно краще за теоретичні межі $H(d) pprox 3..6$ та $f$. **H2:** На адверсарних екземплярах Хватала відношення $	ext{Cost}/	ext{OPT}$ для жадібного алгоритму зростає пропорційно до $\ln n$, тоді як порогове LP-округлення досягає точного оптимуму ($	ext{Cost}/	ext{OPT} = 1.0$). **H3:** Час роботи жадібного алгоритму зростає субоквадратично з показником степеня $eta pprox 1.0..1.2$, дозволяючи розв'язувати екземпляри з $n = 10^5$ менш ніж за $0.5$ с, тоді як LP-методи стають у $\ge 50$ разів повільнішими вже при $n \ge 10^3$. |
| **Стек і середовище** | C# 12 / .NET 8.0 (`global.json`), пакет `Google.OrTools` v9.11.4210 (GLOP для LP, CBC/SCIP для MILP), `xUnit` v2.9.2 для модульних тестів. Наявність `GLOP_LINEAR_PROGRAMMING` та `CBC_MIXED_INTEGER_PROGRAMMING` перевірено. |
| **Мінімальний обсяг / поглиблення** | **Мінімум:** Greedy та LP-округлення проти MILP/LP* на 4 сімействах задач, статистичний аналіз (Вілкоксон, $A_{12}$, Холм). **Поглиблення (виконано):** узагальнення на $k$-покриття з резервуванням ($k \in \{1, 2, 3\}$) та комбіноване рандомізоване LP-округлення з reverse-delete очищенням. |
| **Ризики** | Великий час MILP при $n > 1000$ — усунено обмеженням часу розв'язувача та використанням $	ext{LP}^*$ як нижньої межі на великих розмірностях. |
| **Повторне використання коду практичних занять** | Загальна структура таймера з прогрівом JIT та схема CSV-логування розвивають напрацювання практичного заняття 11; реалізація лінивої купи, $k$-покриття, перешкод прямої видимості, адверсарного генератора та статистичного модуля — нові. |
